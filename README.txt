என் நூலகம் — My library (version 2.2)
======================================

SET UP (once)
1. Unzip this folder anywhere (right-click → Extract All).
2. Copy your book PDFs into the pdfs folder
   (Raja Thilagam goes in pdfs/raja-thilagam/).

OPEN THE LIBRARY — easiest way
  Windows:  double-click  "Start library (Windows).bat"
  Mac:      double-click  "Start library (Mac).command"
            (first time: right-click it → Open → Open, because Mac asks about new files)
  A small window opens and the library opens in your browser. Books open straight
  away, with no folder to choose. Keep that small window open while reading;
  close it when you're done.
  If Windows shows "Windows protected your PC", click "More info" → "Run anyway".

OTHER WAY — double-click index.html
  The browser asks you to choose your books folder the first time.
  Choose the "pdfs" folder (any folder that has the PDFs inside works).
  If the browser asks "Upload files?", click Upload. Nothing leaves your computer.

READING
- ‹ › buttons, the ← → keys, or click the left/right edge of the page.
- Type a page number and press Enter to jump.
- The page fits the screen. + makes it bigger (then you can scroll), Fit puts it back. ☾ is night reading.
- Your page is saved automatically for every part of every book.
  (Pages saved when using the launcher and when using index.html are kept separately.)

ADD A NEW BOOK
1. Make a folder inside pdfs/, e.g.  pdfs/kadal-pura/  and put the PDFs there.
2. Open books.js in Notepad, copy the Raja Thilagam block, change the details.
3. Save, then refresh the browser page.

FOLDERS
- lib/   the built-in PDF viewer (pdf.js by Mozilla) and the launcher's server.
- pdfs/  your books. The .gitignore file keeps this folder off GitHub.
